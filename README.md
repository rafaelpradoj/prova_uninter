# Prova prática Questão 4

Passo 1: Criar e ativar o venv
```bash
    python3 -m venv venv
    source venv/bin/activate
```

Passo 2: Executar a instalação em lote
```bash
    pip install -r requirements.txt
```

Passo 3: Levantar a aplicação
```bash
    uvicorn main_3:app --reload
```
